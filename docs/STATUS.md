# Статус

## Сделано

- Структура Android-проекта, Gradle wrapper, signing, зависимости CameraX/ONNX Runtime.
- Модели детектора и OCR в assets, словарь `ppocrv5_en_dict.txt`.
- Пайплайн: YOLOv8 decode/NMS → crop → PP-OCRv5 CTC → парсер РФ/РБ → трекер.
- UI: PreviewView, рамка, крупный номер, страна/тип/уверенность, настройки.
- Unit-тесты: парсер, трекер, YOLO decode, CTC.
- CI: сборка release APK, тесты, публикация в `latest`.

## Проверено локально

- Формы ONNX: детектор `[1,5,8400]`, OCR `[1,T,438]`.
- OCR на синтетическом изображении `A123BC 77`: распознано `A123BC77`, уверенность ~0.96.
- Словарь: 436 строк, первые 36 классов — цифры и латиница; выход 438 классов, лишние маскируются.
