# Статус

## Сделано

- Структура Android-проекта, Gradle wrapper, signing, зависимости CameraX/ONNX Runtime.
- Модели детектора и OCR в assets, словарь `ppocrv5_en_dict.txt`.
- Пайплайн: YOLOv8 decode/NMS → crop → PP-OCRv5 CTC → парсер РФ/РБ → трекер.
- UI: PreviewView, рамка, крупный номер, страна/тип/уверенность, настройки.
- Unit-тесты: парсер, трекер, YOLO decode, CTC, профили производительности.
- CI: сборка release APK, тесты, публикация в `latest`.
- Оптимизация: профили по железу, XNNPACK/CPU fallback, переиспользование буферов детектора и OCR, ротация без лишних аллокаций, троттлинг OCR, отключение тайлинга на слабых устройствах.
- Модели выгружаются из assets в `filesDir` и грузятся ORT по пути (mmap), чтобы снизить пиковую память.
- LOW-профиль стартует с 2 к/с и разгоняется адаптивно; XNNPACK использует общий пул потоков без CPU spinning. Поля, разделяемые потоками камеры и UI, защищены `@Volatile`, закрытие моделей ждёт завершения анализа.

## Проверено локально

- Формы ONNX: детектор `[1,5,8400]`, OCR `[1,T,438]`.
- OCR на синтетическом изображении `A123BC 77`: распознано `A123BC77`; выход модели — вероятности, уверенность теперь считается напрямую.
- Словарь: 436 строк, первые 36 классов — цифры и латиница; выход 438 классов, лишние маскируются.
