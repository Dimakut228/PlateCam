# PlateCam

Android-приложение для распознавания автомобильных номеров **РФ** и **РБ** в реальном времени. Работает полностью офлайн: кадры не отправляются в сеть, модели лежат в APK.

## Что умеет

- Детекция номера в кадре камеры и рамка поверх изображения.
- Крупный номер в нижней панели с страной, типом и уверенностью.
- Гражданские, такси, прицепы, мото, военные, полицейские, дипломатические, транзитные и специальные форматы РФ и РБ.
- Исправление типичных ошибок OCR (`O/0`, `I/1`, `B/8`, `T/7` и т. п.).
- Подтверждение чтения по нескольким кадрам, чтобы номер не мигал.
- Автоподстройка под устройство: разрешение анализа, число потоков, частота кадров и размер OCR выбираются по ядрам, памяти и 32/64-бит.
- Работа в машине: размытые тряской кадры отбраковываются по резкости в пользу самых чётких, выдержка укорачивается фиксированной частотой кадров, фокус держится непрерывным, позиция номера предсказывается по его движению и OCR читает предсказанную область, пока детектор номер «теряет».
- Ускорение CPU через XNNPACK, переиспользование буферов и пропуск лишних OCR-кадров.
- Настройки: страна, порог детектора, частота анализа, подтверждение, поиск мелких номеров, автоэкспозиция и XNNPACK.
- Автообновление: при запуске (не чаще раза в сутки) приложение проверяет GitHub Releases и предлагает установить новую сборку; в настройках есть пункт «Проверить обновления». Сеть используется только для этой проверки; кадры камеры в сеть не уходят.

## Ограничения

- Точность зависит от освещения, ракурса, загрязнения, скорости и качества камеры.
- Номера на большой дистанции могут требовать режима «Искать мелкие номера».
- Нестандартные и специальные номера могут отображаться как «нестандартный».
- Приложение не является средством официальной фиксации и не заменяет государственные системы.

## Модели и лицензии

| Компонент | Источник | Лицензия |
|---|---|---|
| Детектор номеров | `Murd0ck/LicensePlateDetector_YOLOv8n` | CC BY 4.0 |
| OCR | PaddleOCR PP-OCRv5 mobile, ONNX-сборка `josephinekmj/anpr-models` | Apache 2.0 |
| Базовая архитектура YOLOv8 | Ultralytics | AGPL-3.0 |

Модели включены в `app/src/main/assets`. При распространении APK сохраняйте атрибуцию и соблюдайте условия лицензий.

## Сборка

Локально нужны JDK 17 и Android SDK 34:

```bash
gradle :app:testDebugUnitTest :app:assembleRelease
```

В этом окружении Java и Android SDK нет, поэтому сборка выполняется через GitHub Actions. Workflow собирает APK, запускает unit-тесты и публикует файл в релиз `latest`. Keystore и пароли подписи хранятся в GitHub Secrets и не входят в репозиторий.

Скачать последнюю сборку:

```text
https://github.com/Dimakut228/PlateCam/releases/latest/download/PlateCam.apk
```

## Структура

```text
app/src/main/
  assets/                 ONNX-модели и словарь символов
  java/.../MainActivity.kt  камера, пайплайн, UI
  java/.../PlateDetector.kt детектор YOLOv8 и переиспользуемый letterbox
  java/.../PlateOcr.kt      PP-OCRv5 + CTC и переиспользуемые буферы
  java/.../PlateParser.kt   форматы РФ/РБ и исправление ошибок
  java/.../PlateTracker.kt  трекинг, предсказание движения и подтверждение
  java/.../Sharpness.kt     резкость кадра для отбраковки размытых кадров
  java/.../FrameSelection.kt отбор самых резких кадров при тряске
  java/.../PerformanceTuning.kt профили эконом/средний/быстрый
  java/.../ModelRuntime.kt  XNNPACK с откатом на CPU
  java/.../ModelAssets.kt   выгрузка моделей из APK в filesDir
  res/                    layout, темы, настройки
.github/workflows/        CI-сборка и релиз
```

## Управление

- Наведите камеру на номер; тап по экрану — фокус, экспозиция и баланс белого.
- Автоэкспозиция приглушает пересвет на солнце (отключается в настройках).
- Панель снизу показывает стабильное чтение и степень уверенности.
- «Настройки» — страна, порог, частота анализа, подтверждение, автоэкспозиция и XNNPACK.
